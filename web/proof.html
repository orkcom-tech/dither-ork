dither-ork — proof page

not the application — the application is at /. This page runs the capability check, validates the registry, and renders the whole catalogue end to end through the real WASM and WebGPU paths, stating per effect how much of the frame moved. That last judgement is what no golden image can make: a golden pins what an effect does, not that what it does matches what it is called.

Capabilities

F-UI-12. WebGPU and SharedArrayBuffer are fatal; the other two degrade stated capabilities rather than failing.

Node registry

Every effect module under src/effects/ is discovered by glob and validated as one set at startup. A missing surprise range, a duplicate id or a default outside its own legal range stops the page here rather than degrading Surprise Me silently.

Ordered dithers — WebGPU compute path

The real path: threshold ranks generated in Rust, uploaded as a table, one compute dispatch per effect against the linear-light rgba16float working surface, then read back across the instrumented boundary. Nothing here is a CPU stand-in.

not run

Preprocessing — WebGPU compute path

F-PP-02, 03, 04 and 06: the tone and noise front of the stack, which runs before any kernel sees the frame. These are the nodes whose figures are hardest to read by eye — a levels move that clips nothing and a hue rotation of zero both look exactly like the source — so every caption states how much of the frame changed and how bright the result came out. F-PP-01 (internal resolution), F-PP-05 (curves) and F-PP-07 (uploaded threshold map) have since become descriptors of their own and appear in the families they belong to. F-PP-08 (masking) is a second image edge on the graph rather than a pass, and is not here.

not run

Pattern dithers — WebGPU compute path

F-PT-01…08. Each one quantizes against the palette and emits the index map, exactly as the ordered dithers do; what differs is the screen the threshold comes from. Every figure states how much of the frame the node actually changed, because a pattern dither that renders and changes nothing is the failure this page exists to catch.

not run

Special effects — WebGPU compute path

F-SP-01…16. Preprocessing and post-processing nodes at their declared defaults. Two of them (outline, dilate/erode) read the index map, so the page runs a Bayer 4×4 quantizer immediately upstream of those and shows the pair; anything else runs alone on the source.

not run

Glitch effects — WebGPU compute path

F-GL-01…17. Every one takes an explicit seed and is reproducible; nothing here reads a clock. Defaults throughout, so what you see is what the properties panel opens with.
